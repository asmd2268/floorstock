💡 Smart Parser Guide
Excel Upload (recommended):
• Red background cells → auto-marked as High Alert
• Yellow background → auto-marked as Hazard
• Gray rows → treated as category section headers
• Multi-line cell names (with Enter) → joined into one name
• Missing Min/Max values → carried from previous row
Paste Format (Tab-separated):
Name	Min	Max	HighAlert	Hazard	LASA
Adrenaline 1mg/ml	1	20	yes	no	no
Furosemide 40mg tab	5	20

Backup & Restore / النسخ الاحتياطي والاسترجاع
Master-only protection, health monitoring, export and restore for the ASDHealth Pharmacy module.
⬇ Export complete database backup

Downloads all operational data, department stock, requests, Crash Cart data, controlled-medicine data, settings, and Firestore user profiles into one JSON file.

⬆ Restore database backup

Choose a backup JSON file, then restore it. Existing documents in the managed collections will be replaced by the backup.

Firebase Authentication passwords/accounts are not exported by the browser. Firestore user profiles are included, while existing Firebase Auth accounts remain unchanged.

A free daily snapshot is saved in this browser for the Master account. The system keeps up to 365 daily snapshots and removes the oldest first if browser storage becomes full. This does not replace the manual computer download.
